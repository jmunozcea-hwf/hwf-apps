# Apps HWF (versión web)

- Nota de Pedido (vendedores): https://jmunozcea-hwf.github.io/hwf-apps/ventas/
- HWF Admin: https://jmunozcea-hwf.github.io/hwf-apps/admin/
- Demos con datos ficticios: /demo/ventas/ y /demo/admin/
- Instalar o reinstalar todas las apps: https://jmunozcea-hwf.github.io/hwf-apps/ (página de inicio)

Este repositorio es **público** y solo tiene el código de las apps: no incluye clientes, ventas ni la clave del script.
Cada app pide el código de conexión (HWF1:...) una vez y baja los datos desde el script de Google.
Se genera desde el repositorio privado `hwf-fuente`; no editar a mano.
